# examples/sliced proto

`entpb/ent_messages.proto` is generated by `make gen-sliced` (it runs
`examples/sliced/ent/entc.go`). `entpb/ent_messages.pb.go` is **not**: it comes
from `buf` and is committed, exactly like `examples/basic/proto/entpb`.

After changing a schema under `examples/sliced/ent/schema`:

```sh
make gen-sliced
cd examples/sliced/proto && buf generate
```

CI does not run `buf generate`, so a stale `.pb.go` is caught by `make build`:
a mapper that reads a proto field missing from the file fails to compile.

The mappers live next to their slice, not in one shared package:

- `internal/domain/billing/pbmap/` maps `Invoice` and `LineItem`
- `internal/domain/identity/pbmap/` maps `Account`

Slices reference each other by ID only, so neither mapper package imports the
other slice's domain package.
